# MYSTERY PET AR: TEAM POWER

เกม AR ภาษาอังกฤษสำหรับนักเรียนชั้น ป.6 เล่นครบ 9 กลุ่ม กลุ่มละ 2 ด่าน:

1. **Human Sentence Builder** — นักเรียน 3–4 คนเคลื่อนตัวซ้าย/ขวาเพื่อเรียงส่วนของคำถาม และค้างลำดับที่ถูกต้อง 2 วินาที
2. **Team Power Answer** — นักเรียนเปิดฝ่ามืออย่างน้อย 3 มือ เลือกคำตอบเดียวกัน และรักษาพลังทีมต่อเนื่อง 5 วินาที

คะแนนเต็มกลุ่มละ 20 คะแนน (Stage 1 = 10, Stage 2 = 10) เมื่อครบ 9 กลุ่มจะแสดงตารางคะแนนและผู้ชนะร่วมกรณีคะแนนเสมอ

## ไฟล์สำหรับ GitHub Pages

อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดภายในโฟลเดอร์นี้ โดยให้ `index.html` อยู่ที่หน้าแรกของ repository:

```
index.html
css/style.css
js/app.js
js/game-data.js
js/tracking.js
js/effects.js
```

จากนั้นเปิด GitHub repository → **Settings → Pages** → เลือก **Deploy from a branch** → `main` / `(root)` แล้วกด Save

กล้องทำงานได้เมื่อเปิดผ่าน **HTTPS** (เช่น GitHub Pages) หรือ `localhost` เท่านั้น ไม่ควรเปิดด้วยการดับเบิลคลิกเป็น `file:///...` เพราะเบราว์เซอร์อาจไม่ให้ใช้กล้องหรือโหลด MediaPipe

## เปิดทดสอบในเครื่อง

เปิด Command Prompt หรือ PowerShell ที่โฟลเดอร์เกม แล้วใช้:

```text
python -m http.server 8765
```

จากนั้นเปิด `http://localhost:8765/` ด้วย Chrome

## เตรียมห้องเรียน

- ใช้ Chrome บน Windows เป็นตัวเลือกหลัก และวางหน้าจอแนวนอน
- วางกล้องห่างผู้เล่นประมาณ 2–3 เมตร ให้เห็นช่วงตัวและไหล่ครบ 4 คน
- ผู้เล่นถือป้ายสีใกล้อก: Player 1 แดง, Player 2 น้ำเงิน, Player 3 เขียว, Player 4 เหลือง
- แสงควรสว่างจากด้านหน้า หลีกเลี่ยงแสงย้อนจากหน้าต่าง
- Stage 2 ควรหงายฝ่ามือให้เห็นนิ้วชัดเจน และแยกมือออกจากกันเล็กน้อย
- MediaPipe โหลดจากอินเทอร์เน็ตครั้งแรก จึงควรเปิดเกมและกด START CAMERA ก่อนเริ่มคาบ

## การควบคุมของครู

ปุ่ม **TEACHER** ระหว่างเล่นมี Pause, Restart Current Group, Skip Group, Camera Recalibrate, Flip Camera, Sound และ Debug Mode

Debug Mode ปิดไว้เป็นค่าเริ่มต้น ใช้ทดสอบโดยไม่ต้องมีนักเรียน 4 คน:

- Stage 1: ลากตัวผู้เล่นจำลองซ้าย/ขวาด้วยเมาส์หรือการสัมผัส
- Stage 2: กดปุ่มจำลองฝ่ามือไปที่ A/B/C
- เลือกภารกิจ ทดสอบคำตอบถูก/ผิด และดู landmarks/FPS ได้

## แก้ปัญหากล้อง

- **Camera API unavailable / HTTPS required:** เปิดจาก GitHub Pages หรือ localhost
- **Permission denied:** กดไอคอนกล้องข้างแถบที่อยู่ของ Chrome แล้วเลือก Allow จากนั้น Reload
- **ไม่พบผู้เล่น:** ถอยห่าง เพิ่มแสง และให้เห็นไหล่/ลำตัวชัดเจน
- **คำสลับคน:** ให้ถือป้ายสีตรงอกและอย่าบังป้ายกัน ระบบจะใช้สีร่วมกับประวัติตำแหน่งเพื่อลดการสลับ
- **ฝ่ามือไม่ติด:** หันฝ่ามือเข้ากล้อง กางอย่างน้อย 3–4 นิ้ว และแยกมือไม่ให้ซ้อนกัน
- **เครื่องช้า:** ปิดแท็บอื่นและใช้ Chrome รุ่นปัจจุบัน เกมจำกัด inference ราว 18 FPS สำหรับ Pose และ 20 FPS สำหรับ Hands และไม่รันสองโมเดลพร้อมกัน

## แก้คำถามหรือคำตอบภายหลัง

แก้รายการ `MISSIONS` ใน `js/game-data.js` แต่ละภารกิจมี `pet`, `category`, `chunks`, `question`, `answers` และเลขตำแหน่งคำตอบถูก `correct` (เริ่มนับจาก 0)

หลังแก้ไขให้รัน:

```text
npm test
```

ตัวทดสอบจะจำลอง 300 เกม หรือ 2,700 รอบ เพื่อตรวจจำนวนภารกิจ ความไม่ซ้ำ การสุ่มกลุ่ม และตำแหน่งคำตอบ A/B/C
